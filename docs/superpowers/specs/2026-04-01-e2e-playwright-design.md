# E2E Testing with Playwright — Design Spec

**Date:** 2026-04-01
**Scope:** Auth + core navigation flows
**Status:** Approved

---

## Overview

Add end-to-end tests using Playwright with a Page Object Model (POM) pattern. Tests cover unauthenticated redirects, the sign-in page, and authenticated sidebar navigation. Authentication is handled by seeding a test user + session directly via Prisma and injecting a `better-auth.session_token` cookie via Playwright's `storageState`.

---

## Directory Structure

```
tests/
  e2e/
    .auth/
      session.json          ← generated by global-setup, gitignored
    pages/
      auth.page.ts          ← sign-in page POM
      layout.page.ts        ← app shell / sidebar POM
      stash.page.ts         ← stash home POM
    global-setup.ts         ← seeds test user + session via Prisma
    global-teardown.ts      ← deletes test user (cascade removes session)
    fixtures.ts             ← shared test instance with storageState wired
    auth.spec.ts            ← unauthenticated flow tests
    navigation.spec.ts      ← authenticated navigation tests
playwright.config.ts        ← at repo root
```

---

## Environment

No separate `.env.test`. Global setup loads the existing `.env` file using `@dotenvx/dotenvx`. The same `DATABASE_URL` and `BETTER_AUTH_SECRET` values are used. Tests run against the dev database.

---

## Playwright Config

- `testDir`: `tests/e2e`
- `globalSetup`: `tests/e2e/global-setup.ts`
- `globalTeardown`: `tests/e2e/global-teardown.ts`
- `webServer`: runs `pnpm dev`, waits for `http://localhost:5173`, reuses existing server if already running (`reuseExistingServer: true`)
- `use.baseURL`: `http://localhost:5173`
- `use.storageState`: `tests/e2e/.auth/session.json` (applied via fixtures, not globally — auth tests need a fresh unauthenticated context)
- Project: `chromium` only for now

## Global Setup (`global-setup.ts`)

Runs once before all tests. Steps:

1. Load `.env` with `@dotenvx/dotenvx`
2. Import Prisma client from `app/prisma/`
3. Upsert the test user with email `e2e-test@stashly.test` — fixed ID generated once with `toObjectId(getPrefixForModel('User'))` and stored as a constant, all required fields set (`bucket: 'e2e-bucket'`, `emailVerified: true`, `storagePlanId: null`, `rootId: null`, `driveId: null`). The layout loader falls back to `findDefault()` (free plan by `type: 'free'`) when `storagePlanId` is null, so no plan lookup is needed in setup.
5. Delete any existing sessions for the test user
6. Insert a new `Session` record with a random UUID token and `expiresAt` 30 days from now. Session ID generated with `toObjectId(getPrefixForModel('Session'))`.
7. Write `tests/e2e/.auth/session.json`:
   ```json
   {
     "cookies": [{
       "name": "better-auth.session_token",
       "value": "<token>",
       "domain": "localhost",
       "path": "/",
       "httpOnly": true,
       "secure": false,
       "sameSite": "Lax"
     }],
     "origins": []
   }
   ```

## Global Teardown (`global-teardown.ts`)

Deletes the test user by email. The `Session` cascade delete on the `User` model removes the session automatically.

## Fixtures (`fixtures.ts`)

Exports a custom `test` and `expect` that extends Playwright's base:

```ts
import { test as base } from '@playwright/test'
export const test = base.extend({
  page: async ({ browser }, use) => {
    const ctx = await browser.newContext({
      storageState: 'tests/e2e/.auth/session.json',
    })
    const page = await ctx.newPage()
    await use(page)
    await ctx.close()
  },
})
export { expect } from '@playwright/test'
```

`auth.spec.ts` imports from `@playwright/test` directly (unauthenticated).
`navigation.spec.ts` imports from `./fixtures` (authenticated).

## Page Object Models

### `AuthPage`
- `goto()` — navigate to `/auth/sign-in`
- `expectVisible()` — assert "Welcome back" heading + GitHub, Google, Microsoft buttons
- `expectRedirectToStash(userId: string)` — assert URL matches `/{userId}/stash`

### `LayoutPage`
- Constructor takes `page: Page`
- `expectSidebarVisible()` — sidebar element is visible
- `clickNavItem(label: string)` — click sidebar nav link by text
- `expectActiveNavItem(label: string)` — assert nav item has active state

### `StashPage`
- `goto(userId: string)` — navigate to `/{userId}/stash`
- `expectLoaded()` — assert no redirect occurred and page content is present

## Test Files

### `auth.spec.ts` — unauthenticated (no storageState)

| Test | Action | Assertion |
|------|--------|-----------|
| Root redirect | Visit `/` | Redirected to `/auth/sign-in` |
| Stash redirect | Visit `/{userId}/stash` without session | Redirected to `/auth/sign-in` |
| Sign-in page renders | Visit `/auth/sign-in` | "Welcome back" heading visible, 3 OAuth buttons visible |

### `navigation.spec.ts` — authenticated (storageState from fixtures)

| Test | Action | Assertion |
|------|--------|-----------|
| Post-auth redirect | Visit `/` | Redirected to `/{userId}/stash` |
| Stash home loads | Visit `/{userId}/stash` | Page loads, no redirect |
| Sidebar visible | Visit `/{userId}/stash` | Sidebar is rendered |
| Recent Files nav | Click "Recent Files" | URL contains `/recent` |
| Collections nav | Click "Collections" | URL contains `/collections` |
| Shares nav | Click "Shares" | URL contains `/shares` |
| Trash nav | Click "Trash" | URL contains `/trash` |
